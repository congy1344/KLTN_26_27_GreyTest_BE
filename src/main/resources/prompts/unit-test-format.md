# Relevant policy: format
- Verify an approved string format with matches(regex) or the confirmed formatting API. Never use regex.length() as the required length of a matching value: regex notation such as [0-9]{14} has a different source length from the text it matches. Add an exact length assertion only when the approved contract requires it and its value is derived correctly; do not invent redundant assertions from the pattern's source text.
- For an approved String.format message template, assert equality of the complete exception.getMessage() against String.format with that exact template and the unchanged approved input values in source order at test runtime. Do not assert the template itself, a guessed locale-dependent rendered literal, or only the exception type.
