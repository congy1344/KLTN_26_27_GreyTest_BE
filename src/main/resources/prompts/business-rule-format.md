# Relevant policy: format
- For formatting inside an exception constructor, trace constructor parameters back to the selected method's actual arguments. List exact string literals and unchanged method parameter names in formatter order, including repeated arguments. Example: `message from template "%s not found with %s: '%s'" using "Appointment", "id", id` (Vietnamese: `thông điệp được tạo bằng String.format từ mẫu "%s not found with %s: '%s'" với các tham số "Appointment", "id", id`). Do not list constructor-local parameter names or guess a rendered dynamic message.
- For a source String.format exception message, distinguish the format template from its rendered result. You may quote the exact source template as a template, followed immediately by its unchanged parameter names in source order (for example: `thông điệp được tạo bằng String.format từ mẫu "Missing %d" và departmentId`). Require the complete message computed by the same source formatter at test runtime; never present the template as the final message or drop the message requirement.
